# 📱 RemoteLink — Privacy-First Android & PC Companion

**RemoteLink** হলো একটি নিরাপদ, দ্বিমুখী ডিভাইস কানেক্টিভিটি ও ফাইল ট্রান্সফার অ্যান্ড্রয়েড অ্যাপ যা লোকাল ওয়াই-ফাই বা ইন্টারনেটের মাধ্যমে আপনার পিসির ওয়েব প্যানেলের সাথে যুক্ত হয়। অ্যাপটিতে রয়েছে স্পষ্ট সম্মতি (Consent-based security), ক্যামেরা কিউআর স্ক্যানার, নোটিফিকেশন মিররিং, ডাইনামিক থিম এবং ফায়ারবেস জেমিনি এআই অ্যাসিস্ট্যান্ট।

---

## 🚀 গিটহাব (GitHub) থেকে সরাসরি APK তৈরি ও রিলিজ করার নিয়ম

এই রিপোজিটরিতে **GitHub Actions CI/CD অটোমেশন** কনফিগার করা হয়েছে, যাতে গিটহাবে পুশ করার সাথে সাথেই স্বয়ংক্রিয়ভাবে অ্যান্ড্রয়েড `.apk` তৈরি হয়ে রিলিজ সেকশনে চলে আসে।

### পদ্ধতি ১: গিটহাব অ্যাকশন্স থেকে এক ক্লিকে APK তৈরি (One-Click Manual Build)

১. আপনার গিটহাব রিপোজিটরির **Actions** ট্যাবে যান।
২. বাম পাশের তালিকা থেকে **"Build & Release Android APK"** সিলেক্ট করুন।
৩. ডানদিকের **"Run workflow"** বাটনে ক্লিক করুন:
   - **Build Type:** `debug` বা `release` বেছে নিন।
   - **Create a GitHub Release:** চেকমার্ক টিক দিয়ে রাখুন।
   - **Run workflow** বাটনে চাপ দিন।
৪. ২-৩ মিনিটের মধ্যে বিল্ড শেষ হলে:
   - **Releases** সেকশনে গিয়ে নতুন তৈরি হওয়া `RemoteLink-v1.0-debug.apk` বা `release.apk` ফাইলটি সরাসরি ডাউনলোড করে ফোনে ইনস্টল করে নিন।
   - অথবা ওই অ্যাকশন রানের নিচের **Artifacts** সেকশন থেকেও সরাসরি জিপ ফাইল ডাউনলোড করতে পারবেন।

---

### পদ্ধতি ২: গিট ট্যাগ পুশ করে অটোমেটিক রিলিজ তৈরি (Git Tag Release)

যেকোনো নতুন ভার্সন রিলিজ করার জন্য আপনার টার্মিনালে নিচের কমান্ড দিন:

```bash
git tag v1.0.0
git push origin v1.0.0
```

গিটহাব নিজে থেকেই ট্যাগ শনাক্ত করে সম্পূর্ণ নতুন একটি **GitHub Release** তৈরি করবে এবং সরাসরি ডাউনলোডযোগ্য APK ফাইল অ্যাটাচ করে দেবে।

---

### ফোনে APK ইনস্টল করার নিয়ম:

১. মোবাইলের ব্রাউজার দিয়ে গিটহাবের **Releases** পেজে যান।
২. `.apk` ফাইলে ক্লিক করে ডাউনলোড করুন।
৩. ডাউনলোড শেষে ফাইলটিতে ট্যাপ করুন। ব্রাউজারে প্রথমবারের জন্য "Install unknown apps" পারমিশন চাইলে "Allow" দিন।
৪. ইনস্টল সম্পন্ন হলে অ্যাপটি ওপেন করুন!

## 🛠️ প্রধান ফিচারসমূহ (Key Features)

1. **🔐 জিরো-ট্রাস্ট ও সম্মতি সুরক্ষা (Explicit User Consent):**
   - কোনো ডেটা বা ফাইল আদান-প্রদান শুরু হওয়ার আগে ফোনে স্পষ্ট "Allow / Deny" ডায়ালগ আসে।
   - ব্যবহারকারী অনুমতি না দিলে বা ডিসকানেক্ট হলে তৎক্ষণাৎ সেশন বাতিল হয়ে যায়।

2. **⚡ দ্রুতগতির ফাইল ট্রান্সফার (64KB Chunks):**
   - অ্যান্ড্রয়েডের জিরো-স্টোরেজ-পারমিশন ডকুমেন্ট পিকারের মাধ্যমে পিসিতে ফাইল পাঠানো।
   - পিসির প্যানেল থেকে ফোনে ফাইল পাঠানোর অফার এলে নোটিফিকেশন আসে এবং ব্যবহারকারী সম্মতি দিলে সরাসরি **Downloads** ফোল্ডারে সংরক্ষিত হয়।

3. **🔔 নোটিফিকেশন মিররিং (Notification Mirror):**
   - `NotificationListenerService` এর মাধ্যমে প্রয়োজনীয় ফোন নোটিফিকেশন পিসির ওয়েব প্যানেলে মিরর হয়।
   - গুগল প্লে নীতিমালার স্বচ্ছতা রক্ষার জন্য ফোনে সবসময় একটি চলমান নোটিফিকেশন দৃশ্যমান থাকে।

4. **✨ জেমিনি এআই অ্যাসিস্ট্যান্ট (Firebase AI Logic - gemini-3.8-flash):**
   - **Alert Digest:** দীর্ঘ নোটিফিকেশন মেসেজ সামারাইজ করে গুরুত্বপূর্ণ ও জরুরি অ্যাকশন আইটেম আলাদা করে।
   - **File Inspector:** ট্রান্সফার করা ফাইলের নিরাপত্তা ও ফরম্যাট বিশ্লেষণ।
   - **Network Doctor:** ওয়াই-ফাই আইপি ও ফায়ারওয়াল পোর্ট 8080 সম্পর্কিত যেকোনো প্রশ্নের তাত্ক্ষণিক সমাধান।

5. **🎨 ডাইনামিক থিম ও নাইট মোড:**
   - ডার্ক মোড (লো-লাইট ও ওলেড ব্যাটারি সেভিং)।
   - লাইট মোড (উজ্জ্বল দিনের আলোতে ব্যবহারের জন্য)।
   - অ্যান্ড্রয়েড ১২+ ম্যাটেরিয়াল ইউ (Material You) ডাইনামিক কালার সাপোর্ট।

6. **💻 ইন-অ্যাপ সার্ভার ও প্যানেল হাব (Server Hub):**
   - অ্যাপের ভেতরেই পিসির জন্য প্রয়োজনীয় `server.js` এবং `panel.html` কোড দেওয়া আছে, যা এক ক্লিকে কপি করে পিসিতে চালানো যায়।

## 🖥️ পিসিতে লোকাল রিলে সার্ভার চালানোর নিয়ম

১. পিসির যেকোনো ফোল্ডারে টার্মিনাল/সিএমডি খুলে রান করুন:
   ```bash
   npm init -y && npm i ws
   ```
২. অ্যাপের **Server** ট্যাব থেকে কোড কপি করে ফোল্ডারে `server.js` এবং `panel.html` নামে সেভ করুন।
৩. সার্ভার চালু করুন:
   ```bash
   DEV=1 node server.js
   ```
   *(Windows CMD: `set DEV=1 && node server.js`)*
৪. পিসির ব্রাউজারে `http://localhost:8080` খুলুন এবং **Generate Pairing Code** দিন।
৫. অ্যান্ড্রয়েড অ্যাপ থেকে কিউআর স্ক্যান করে যুক্ত হোন!
